# HGhubX TV tv-v3.0.0-pre.2

HGhubX TV 3.0 第二个预发布版本（`com.hghubx.tv`）：支持手机扫码双向同步与自定义视频源扩展，同步合入启动稳定性修复与安装包瘦身优化。

## 新增与优化
1. **视频源管理与离线示例试用**：支持手机局域网扫码 / 4 位 PIN 码推源、`hghubx://` 深链导入及进入时静默检查更新；引导页与「设置 → 视频源」新增「试用离线示例源」与一键「移除示例源」，方便无源状态下先体验界面布局与导航交互。
2. **手机与 TV 双向同步配对**：支持一次扫码配对后同局域网双向同步片库收藏、观看进度、内容屏蔽偏好与播放设置，并在「设置 → 手机同步」管理已配对设备。
3. **真实缓存清理与最高无上限档位**：TV「设置 → 缓存」支持 `128 MB` / `256 MB` / `512 MB` / `1 GB` / `无上限` 5 档调节与真实清理释放，保留本机片库、同步记录与启动 PIN。
4. **关于页图标与包体积优化**：「设置 → 关于」展示正式应用 Logo；启用 R8 资源裁剪与原生库压缩，Android TV APK 体积大幅缩小。

## 修复
1. **修复 Android TV 启动闪退（#276）**：原地替换模板默认 `FileProvider` 声明，消除部分设备上因重复 `ContentProvider` 导致的开机崩溃。
2. **请求连接池与 DoH 回退（#266）**：复用底层 HTTP 连接池并支持受控 DoH 回退，改善复杂网络下的线路失败与误报。

## 安装与兼容提示
- Android TV 按 ABI 分包提供 `HGhubX-TV_3.0.0-pre.2_arm64.apk`、`HGhubX-TV_3.0.0-pre.2_arm.apk`、`HGhubX-TV_3.0.0-pre.2_x86_64.apk`（`com.hghubx.tv`，`versionCode=3000000`）。
- 沿用既有签名证书与版本序列，支持覆盖安装并保留本机片库、观看记录、启动 PIN 与偏好设置。
