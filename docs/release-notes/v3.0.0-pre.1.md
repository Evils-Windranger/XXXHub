# HGhubX v3.0.0-pre.1

3.0 架构脱壳重构首个预发布版本：客户端全面演进为纯壳运行时与 QuickJS 插件沙箱架构，覆盖 Windows、macOS、Linux、Android 与 iOS；欢迎试用反馈。

## 新增与优化
1. **纯壳重构与 QuickJS 视频源插件架构**：剥离所有站点专属耦合，由独立的 Ed25519 验签/口令视频源插件声明能力、分类频道、加解密与线路发现规则；支持扫码、剪贴板口令、JSON、文件、`hghubx://` 深链导入与「视频源」热切换、版本回滚及连通性测试。
2. **手机与 TV 局域网双向同步配对**：支持手机端「扫一扫」识别 TV 二维码或 4 位配对码直连电视端，同步视频源配置、本机收藏/观看记录、内容偏好与常用播放设置。
3. **作者目录与标签加载提速**：作者目录改为第 1 页即刻上屏渲染并在后台以 4 并发渐进补齐分页；「标签」「专题」与搜索页「热门题材」接入按源与线路隔离的 SWR 本地缓存，二次进入零等待展示并静默更新；优化 QuickJS 源存储写锁竞争与原子落盘。
4. **收藏页下拉刷新检查剧集更新**：在「我的 → 我的收藏」支持顶部下拉手势及工具栏「刷新收藏」按钮，同步云端记录并比对剧集总数变化，即时提示更新部数与新增集数；未干扰左右滑切与筛选体验。
5. **真实跨平台缓存清理与最高无上限档位**：支持 `128 MB`、`256 MB`、`512 MB`、`1 GB` 与「无上限」5 档调节与持久化，调低立即按 LRU 淘汰；统一真实统计内存缓存与磁盘纯缓存目录占用，并在 Linux（WebKitGTK 媒体/缓存）、macOS/iOS（`NSURLCache` 与系统缓存目录）、Windows（仅 WebView2 缓存目录）及 Android（原生 `WebView.clearCache(true)` 桥接）执行安全清理，完整保留登录态、收藏、观看记录与设置。
6. **视频源每次进入静默更新**：每次冷启动及从后台返回前台（60 秒冷却）时静默检查带 `updateUrls` 的已安装源，有新版时自动后台应用并在活动源域名变更时同步线路，无报错弹窗打扰。
7. **扫码界面画质与对焦升级**：「扫一扫」改用 1080p/720p 高清流优先约束与主摄识别策略，开启连续自动对焦、点击画面对焦及多后置镜头切换按钮，并优先直连硬件 `BarcodeDetector` 解码。
8. **界面与体积优化**：去掉视频源导入输入框提示文字；「关于 HGhubX」弹窗换回正式应用 Logo；打包链路瘦身（拆出独立音量均衡依赖、精简 HLS 运行时及开启 Android 资源与 `.so` 压缩）。

## 修复
1. **视频源导入「粘贴」权限不足**：在 Tauri capability 开放 `clipboard-manager:allow-read-text`，前端统一经原生插件 `readText()` 读取剪贴板，解决移动端与桌面 WebView `navigator.clipboard.readText()` 被拦截的问题。
2. **分类页功能布局与排行榜/标签错位**：按能力门控恢复完整分类页快捷入口，修正紧凑双格按钮居中对齐与文字错位，支持无 `popularAuthors` 源隐藏作者入口。
3. **iOS 未签包侧载「文件损坏」与插件源连接池（#261、#266）**：iOS 打包脚本补齐扩展属性清理、`codesign` ad-hoc 签名与 `LC_CODE_SIGNATURE` 校验，并补全 `Info.ios.plist` 深链与权限描述；QuickJS `host.fetch` 接入按源域名复用的 HTTP 连接池与受控 DoH 回退，改善代理与 DNS 异常导致的线路全线失败。

## 安装与兼容提示
- Windows 提供 NSIS 安装包与便携压缩包；macOS 提供 Universal DMG；Linux 提供 amd64 `.deb`/`.rpm`；Android 提供按 ABI 分包签名 APK（`versionCode=3000000`）；iOS 提供已 ad-hoc 签名的 `.ipa`（需自行重签侧载安装）。
- 本版为纯壳预发布版（Pre-release），升级后需按提示重新导入社区或个人视频源插件口令；既有收藏、观看记录与偏好设置均予保留。
